AISC LAB ESE - EASY PYTHON EXAM CODES

Topics:
01 Water Jug (BFS / DFS)
02 A* Algorithm for 8-Puzzle
03 Half Adder and Full Adder
04 Single Layer Perceptron - AND, OR, NOT + decision boundary graph
05 Backpropagation - XOR + error plot
06 SOM and LVQ - Iris data, clustering, classification + plots
07 Associative Memory - Hopfield + BAM + plots
08 Fuzzy Sets - triangular membership and fuzzy relation heatmap
09 Fuzzy Logic Controller - temperature controlled fan + membership graph

Install once:
  python -m pip install numpy matplotlib scikit-learn minisom scikit-fuzzy

Run e.g.:
  python 05_backpropagation.py

Notes:
* 01 and 02 cover topics missing/not exactly matched in your PDFs.
* 06 requires minisom, 09 requires scikit-fuzzy.
* These are simpler teaching versions; 06/09 follow the PDF library approach.
* The scripts create plots as PNGs in the directory where you run them.
